Privacy Policy

Last updated: October 25, 2026

Video Factory is a personal desktop tool that runs on its owner's own computer. It is used only by the owner to manage the owner's own YouTube channels.

What data the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to read the basic information of the owner's channel (name and ID) and to upload videos, thumbnails and captions to that channel.

How data is stored

The access token is stored only on the owner's computer. No data is sent to any server operated by the app, and no data is sold, shared or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
